# 调查与实施：处决具体死法（斩首 / 做成神秘的肉）

> 起因：郭氏战役 1197.6.12 郭靖处决波兰女王玛丽亚·皮雅斯特（56852）时，游戏界面
> 可选择「斩首」或「做成神秘的肉」（后者为无地冒险者 恐惧税 天赋的专属处决方式）。
> 传记当前只写「被郭靖处决」。

## 结论（调查部分）

**存档读不到具体死法——CK3 存档不记录处决方式。** 所有处决方式（斩首/做成肉/
烧死/食人/献祭/犬决）在受害者死因上都写同一个键 `death_execution`，且无任何附带
记忆、秘密、标志或变量（证据见下）。

## 实施（2026-09-02，用户批准后）

既然永远「处决」单调，改为**按行刑者当时可用的 `send_option` 稳定伪随机选一种死法**：

- `facts.py` 新增 `execution_method(killer, victim, date)`：近似复现
  `execute_prisoner_interaction` 的 send_option 可用条件（以传记所用熔件/缓存的
  行刑者状态判定）：
  - 斩首：东亚系文化模板（asian heritage 支柱近似）或与受害者同信仰；文化未知默认可用；
  - 烧死：非东亚系文化（与斩首互斥方向）；
  - 做成神秘的肉：`landless_adventurer_government` + `fear_tax_perk`；
  - 犬决：雇有 `kennelperson_camp_officer`（猎犬人）廷臣；
  - 食人：`cannibal` 特质（trait_history 按日期判定）或 `secret_cannibal`；
  - 献祭：需信仰 `human_sacrifice_active` 教义（存档无教义参数表，暂不判定）。
  - 从可用方式中按 `md5(行刑者:受害者:日期)` 种子取一 → **同一次处决重跑不漂移**，
    不同处决有变化。
- `_death_sentence`：`death_execution` 且行刑者已知时改用该短语
  （被郭靖斩首 / 被郭靖做成神秘的肉充作口粮 …），其余死因不变。
- 郭氏实测：1197–1199 玩家 4 次处决 → 斩首 ×2 / 做成肉 ×2；1197 年习得恐惧税
  前（as_of 1197 视角）仅剩斩首。
- 验证：`experiments/verify_execution.py`（含稳定性/非处决不受影响/无天赋仅斩首）。

## 调查证据（存档为何不可读）

1. **死因键统一**：游戏 `common/scripted_effects/00_prison_effects.txt` 的
   `execute_prisoner_effect` 对所有方式统一写 `death_reason = death_execution`；
   `00_prison_interactions.txt` 中「斩首」(execution_beheaded)、「做成神秘的肉」
   (execution_provisions，需 `landless_adventurer_government` + `fear_tax_perk`)、
   「烧死」(execution_burned)、「食人」(execution_devour)、「献祭」
   (execution_sacrifice)、「犬决」(execution_kennel) 只是不同的 `send_option` 标志，
   受害者侧死因不随方式变化。
2. **玛丽亚熔件全字段**（1188–1200 各熔件 `dead_unprunable`）：`dead_data` 仅含
   date/reason/killer/liege/liege_title/domain/memories/government/flavor；
   角色记录无任何方式相关 flag/variable。
3. **处决事件不留痕**：`char_interaction.0170/0171`（行刑演出）不设任何 flag。
4. **无相关记忆**：玛丽亚与玩家两侧均无 exec/eat/behead 等记忆类型。
5. **无相关秘密**：secrets 段中玩家只有 `secret_murder`（不含 56852）；
   玩家无食人秘密、无 cannibal trait → 未用「食人」。
6. **横向一致**：玩家全部 4 名被处决受害者死因键全是 `death_execution`。
7. **做成肉的唯一副作用是瞬时的**：`scope:actor.domicile.change_provisions =
   human_provision_value`（给营地加口粮），年度熔件快照中营地 provisions=0，
   无法归属到某次处决。
