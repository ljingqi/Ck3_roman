# 审计：传输给模型的事实文本自然度（确定性清单）

> 基准：`main` 分支 v28b 实施后（称谓统一 + 隐事省词元）。
> 方法：程序导出传输面 → 逐块按 10 条判据核对 → 分级为 P0（已修）/ P1（待改）/ P2（观察）。
> 只读工具：`experiments/dump_prompt_blocks.py`（导出全部 system/user 到 `output/audit/`）、
> `experiments/measure_prompt_size.py`（逐块字符数）、`experiments/verify_label_styles.py`。
> 交付形态（用户拍板 2026-09-10）：**确定性清单**（不做模型侧评分）。

## 二、判据（10 条）

1. 无裸字段标签、等号、英文键（块头如「【传主】」不算）。
2. 每行是完整句（主语+谓语+句末标点），不是「标签：值」串。
3. 「：」不连续嵌套。
4. 括号单层、只作必要补注、不与正文重复。
5. 日期/数字/术语写法统一（公元年月日、量词、职衔动词）。
6. 称谓与 `person_label` 口径一致，同一人全篇同一称谓。
7. 无元信息（出身自定/史无可考/存档来源/生成时间）。
8. 同一次请求内无重复信息。
9. 用词不与提示词规则冲突（如 `PLAIN_WORD_RULE`）。
10. 无占位兜底串（`（无X记录）`/`一位人物`/`名讳不详`）。

## 五、P2（观察项）

- 「【概览】一生谋杀31次、添丁4次…」机械计数：保留（数据锚点，模型据此控制篇幅）。
- 「死者：…／亲缘：…／婚恋：」标签行：可读性尚可，暂不动。
- 称号用词（「高御座天皇」「可萨布兰部颉利发」）来自游戏本地化，保持原样。
- `_lead_digest` 截断处（`biography.py:522`）可能断在句中，配「……」尚可读。

## 六、验收方式（每批改动）

1. `python experiments/dump_prompt_blocks.py <家族>` 前后各导一次，`diff` 逐块核对。
2. `verify_lushi` / `verify_tadokoro2` / `verify_kin_label` / `verify_label_styles` /
   `verify_secrets` / `verify_ctx_slim` / `verify_e2e_mock` 全 PASS。
3. `measure_prompt_size.py blocks <年份>` 确认**提示词字符数不增**（自然化不得以膨胀为代价）。
4. 提示词一律正向表述（见技能 `no-negative-prompts`）。
